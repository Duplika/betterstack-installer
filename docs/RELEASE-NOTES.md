# 4.0.0-rc3 — candidata pública

Primer instalador público sin perfiles reales ni credenciales, con build reproducible y verificación previa a ejecución. Detección automática AlmaLinux/CloudLinux, edición Solo sin LVE, monitoreo acotado, identidad de versiones y observaciones KernelCare/reinicio.

Agrega configuración local del destino y captura interactiva oculta del token, sin sobrescribir archivos existentes. Conserva migraciones verificadas de layouts v3, checkpoints, buffers y extensiones reconocidas.

Estado: candidata pendiente de preflight, ensayo y aceptación remota. El resultado local/CI no demuestra consumo real ni entrega de métricas. No usar para una migración masiva todavía.
